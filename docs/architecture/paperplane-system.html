Paperplane 4.2.1

One local Streamlit process with automatic native/vision routing and no document persistence.

1 · Streamlit workspaceUpload, preview, select mode, parse, inspect cost and output, and download.
2 · In-process runtimeReuse Docling model resources and create one short-lived provider client per parse.
3 · Validate and routeEnforce limits and classify native versus scan-like PDF pages.
4 · Local DoclingConvert native PDFs and Office/OpenDocument/CSV structure.
5 · Selectable visionUse one of six verified cloud model IDs with deterministic grounding.
6 · Shared assemblerValidate reading-order Markdown and grounding while aggregating provider token usage.
7 · Evidence PDFOverlay grounded source boxes or list semantic-only Office evidence.
8 · Session resultOutput, annotated PDF, Markdown, and JSON remain available for explicit download.
Trust and state boundaryStreamlit binds to 127.0.0.1. Uploads and results live only in the current session. Scans, images, and requested figure crops go to the selected model provider endpoint.
