# Support

Paperplane is an open-source community project. Support is best-effort; there is no paid
support service or guaranteed response time.

## Help the project

- Star and share the [GitHub repository](https://github.com/pypi-ahmad/Agentic-Document-Extraction).
- Test Paperplane with synthetic, redacted, or redistributable documents.
- Submit a [bug report](https://github.com/pypi-ahmad/Agentic-Document-Extraction/issues/new?template=bug_report.yml)
  with reproducible steps and sanitized logs.
- Suggest an improvement through the
  [feature request form](https://github.com/pypi-ahmad/Agentic-Document-Extraction/issues/new?template=feature_request.yml).
- Improve code, tests, or documentation by following [CONTRIBUTING.md](CONTRIBUTING.md).

## Getting help

Search [existing issues](https://github.com/pypi-ahmad/Agentic-Document-Extraction/issues)
before opening a new report. Include the Paperplane version, operating system, selected
engine and model, affected page range, expected result, actual result, and the smallest safe
reproduction you can provide.

Never publish API keys, private documents, unredacted provider responses, or confidential
output. Use synthetic or redacted samples that you have the right to share.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not
through a public issue.
